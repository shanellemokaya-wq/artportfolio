 # Artist Portfolio & E-commerce Website

A responsive portfolio and e-commerce website designed and developed from scratch to showcase and sell my artwork.

## Features

- Responsive portfolio and shop interfaces
- Custom JavaScript gallery and image viewer
- Interactive magnification for artwork
- Shopping cart and product configuration
- Stripe Checkout integration
- Cloudflare Worker backend for checkout and webhooks
- Automated transactional email workflow
- Responsive mobile navigation and layouts

## Technologies

- HTML
- CSS
- JavaScript
- Cloudflare Workers
- Stripe
- GitHub Pages
